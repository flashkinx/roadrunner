      Google

      Der Key liegt im macOS-Schlüsselbund, nicht in einer Datei.

      So legst du den API-Key bei Google an rund 10 Minuten

      Du brauchst ein Google-Konto und eine Kreditkarte. Roadrunner nutzt zwei Google-Dienste: die Routes API für die Fahrzeit mit Verkehr und die Places API (New) für die Adresssuche. Google schenkt dir jeden Monat 5.000 Fahrzeit-Abfragen. Mit den Standardeinstellungen braucht Roadrunner rund 3.650, kostet also nichts. Darüber verlangt Google 10,00 USD je 1.000 Abfragen.

      1. Projekt anlegen. Name zum Beispiel „Roadrunner“, dann „Erstellen“. Danach oben links prüfen, dass dieses Projekt ausgewählt ist. Öffnen
      2. Abrechnungskonto verknüpfen. Kreditkarte hinterlegen. Ohne Abrechnungskonto liefert Google auch die Gratis-Abfragen nicht. Öffnen
      3. Routes API aktivieren. „Diese API aktivieren“ klicken. Beim ersten Mal fragt Google nach den Nutzungsbedingungen für den EWR: ins Feld „Bestätigen“ tippen, dann „Akzeptieren und weiter“. Öffnen
      4. Places API (New) aktivieren. Achtung, nicht die alte „Places API“ ohne den Zusatz „(New)“. Öffnen
      5. Key anlegen und einschränken. Meist hat Google beim Aktivieren schon einen „Maps Platform API Key“ angelegt, sonst „Anmeldedaten erstellen“ → „API-Schlüssel“. Den Key anklicken, unter „API-Einschränkungen“ nur Routes API und Places API (New) auswählen, „Anwendungseinschränkungen“ auf „Keine“ lassen, „Speichern“. Öffnen
      6. Kostenbremse (empfohlen). Kontingente der Routes API, Zeile „Directions - ComputeRoutes per request quota per day“ → „Kontingent bearbeiten“, „Unlimited“ abwählen, 200 eintragen, „Anfrage senden“. Mehr als 200 Abfragen am Tag lässt Google dann nicht zu. Öffnen
      7. Key übernehmen. Bei den Anmeldedaten „Schlüssel anzeigen“, kopieren, oben einfügen und „Sichern“. Fragt macOS nach dem Schlüsselbund: „Immer erlauben“.

      Oder einen Claude-Assistenten machen lassen

      Ein Claude mit Browsersteuerung (z.B. Claude in Chrome oder Claude Code mit Browser) kann die Schritte 1 bis 6 für dich erledigen. Auftrag kopieren und ihm geben. Kreditkarte, Nutzungsbedingungen und das Kopieren des Keys bleiben bewusst bei dir.

      Richte mir in der Google Cloud Console einen API-Key für die Mac-App „Roadrunner“ ein. Ich bin im Browser bei Google angemeldet. Die App berechnet Fahrzeiten mit Verkehr (Google Routes API, computeRoutes mit TRAFFIC_AWARE) und sucht Adressen (Places API (New), Autocomplete und Place Details).

Schritte:
1. Projekt „Roadrunner“ anlegen (console.cloud.google.com/projectcreate) oder ein vorhandenes gleichnamiges Projekt auswählen. Arbeite danach ausschließlich in diesem Projekt.
2. Prüfen, ob ein Abrechnungskonto verknüpft ist. Wenn nicht: zur Verknüpfungsseite führen und mich die Zahlungsdaten selbst eingeben lassen.
3. Routes API aktivieren (routes.googleapis.com).
4. Places API (New) aktivieren (places.googleapis.com), nicht die alte Places API.
5. Unter APIs und Dienste → Anmeldedaten einen API-Key verwenden (der automatisch angelegte „Maps Platform API Key“ ist in Ordnung, sonst einen neuen anlegen). Umbenennen in „Roadrunner (Routes + Places)“. API-Einschränkungen: ausschließlich Routes API und Places API (New). Anwendungseinschränkungen: Keine. Speichern und in der Liste prüfen, dass „2 APIs“ dasteht.
6. Kostenbremse: In den Kontingenten der Routes API „Directions - ComputeRoutes per request quota per day“ von „Unbegrenzt“ auf 200 setzen und die Rückfrage bestätigen. Danach den Wert in der Liste gegenprüfen.

Harte Regeln:
- Gib keine Kreditkarten- oder Zahlungsdaten ein.
- Akzeptiere keine Nutzungsbedingungen für mich (z.B. den EWR-Dialog beim Aktivieren). Halte an, sag mir, was ich tippen und klicken muss, und mach danach weiter.
- Lies den API-Key nicht aus und schreib ihn nirgends hin. Sag mir am Ende nur, wo ich auf „Schlüssel anzeigen“ klicke, damit ich ihn selbst kopiere.
- Lösche nichts und ändere nichts an anderen Projekten.
